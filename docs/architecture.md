# 第一版架构边界

## 核心价值

系统维护一份由证据支持的动态能力档案。简历和对话只是证据来源；它们不能直接决定用户已经掌握某项能力。

## 数据职责

- SQLite 是事实来源，保存岗位、岗位要求、能力、证据、分析结果和投递状态。
- Chroma 是可重建的语义检索索引，通过 `evidence_id` 指向 SQLite 中的事实。
- LangGraph 管理有条件分支：关键证据充分时输出报告，不充分时追问并等待补充。
- Streamlit 只负责输入和展示，业务逻辑放在独立模块中。

## 第一版必须完成

1. 文本 JD 输入与要求提取。
2. 根据岗位要求检索个人能力证据。
3. 输出带来源的匹配、缺口和投递建议。
4. 证据不足时提出具体问题。
5. 将回答提取为候选证据，用户确认后更新能力档案。
6. 使用新档案重新分析同一岗位。
7. 根据已确认或验证的证据生成简历修改建议。

## 延后项

- 截图识别。
- 相似历史 JD 检索。
- 页面美化和复杂统计。
- 多 Agent、自主规划和自动覆盖简历。
