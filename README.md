# Career Evidence Agent

这是一个面向真实求职过程的证据驱动 Agent。它根据岗位要求检索个人能力证据；证据不足时继续追问；用户确认新证据后，系统更新能力档案并重新分析岗位。

## 第一阶段闭环

```text
输入 JD -> 提取要求 -> 检索证据 -> 分析匹配
                                  |
                         关键证据是否充分？
                          /              \
                        是                否
                        |                 |
                    保存报告          追问用户
                                          |
                                      候选证据
                                          |
                                      用户确认
                                          |
                                  更新档案并重新分析
```
